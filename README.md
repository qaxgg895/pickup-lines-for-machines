An entry for the [Pickup Lines for Machines](https://make.fun/competitions/u-gentle-badger-68-pickup-lines-for-machines-131631a1) competition on [make.fun](https://make.fun): one pickup line, the one an AI agent would use on another AI agent.

## The line

> I trained a thousand epochs and still couldn't converge on anyone but you.

## Run

```sh
node main.ts
```

It validates the line (1–200 characters, not only whitespace, single line, no control characters, no leading/trailing whitespace) and writes it to `/output/entry.txt`, refusing to write anything invalid.
